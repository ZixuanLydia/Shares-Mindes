# Collage materials

Seven AI-generated paper-collage materials, prepared in advance: a blue cloud, a golden crescent moon, a red house with a blue roof, a golden sun, a sage-green tree, a coral flower and a blue bird.

They are reusable pieces inside the collage board. The website does not make live AI calls.

The four Week 5 additions were generated with the built-in image generation tool using cloud.png and house.png as style references. Original transparent PNG alpha is preserved. Exact prompts are recorded in sticker-prompts.txt. Week 3 and Week 4 assets are unchanged.
